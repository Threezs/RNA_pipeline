# Project starter

Copy this directory into a project folder and complete PROJECT_STATUS.yml
before running analysis.

## Required decisions

- What is the biological experimental unit?
- How many independent biological replicates are in each group?
- What is the primary contrast and reference group?
- Which raw-data and annotation versions are used?
- Which analysis is primary, and which are sensitivity analyses?
- Which limitations must appear in the final report?

Keep large or controlled data outside Git. Record the path or accession and a
checksum in the project status file. Add a row to the run ledger after every
meaningful execution.
